# Product photos

Save each photo as `public/products/<number>.jpeg` (`.jpg`, `.png` and `.webp` also work).
Then run `npm run db:seed` so the site picks up the file names. If two files share a
number, the newest one is used.

Photo guidelines: one case, back view, camera visible, plain light background,
portrait 4:5, at least 1000x1250 px, no logos / brand text / watermarks.
